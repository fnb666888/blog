## 一、声音是什么

### 1. 机械波的本质
声音是**介质中的机械纵波**，不是电磁波，不能在真空中传播。

- **纵波**：质点振动方向与波传播方向平行（区别于光的横波）
- **传播机制**：局部压缩→压力升高→推动邻近质点→邻近区域压缩→原区域稀疏恢复……如此传递能量而非物质
- **介质依赖**：声速由介质的弹性模量和密度决定

$$c = \sqrt{\frac{K}{\rho}}$$

| 介质 | 声速 (20°C) | 说明 |
| :--- | :--- | :--- |
| 空气 | ~343 m/s | 温度每升1°C约+0.6m/s |
| 水 | ~1482 m/s | 约为空气的4.3倍 |
| 钢 | ~5960 m/s | 固体中更快 |
| 真空 | 0 | 无法传播 |

### 2. 三个基本物理量

| 物理量 | 符号 | 单位 | 对应感知 |
| :--- | :--- | :--- | :--- |
| 频率 | f | Hz | 音高 (Pitch) |
| 振幅/声压 | p | Pa / dB SPL | 响度 (Loudness) |
| 波形/频谱 | - | - | 音色 (Timbre) |


### 3. 声压级与分贝

人耳可感知的声压范围从 $2\times10^{-5}$ Pa（听阈）到 ~20 Pa（痛阈），跨越**六个数量级**。线性刻度不实用，因此使用对数标度：

$$L_p = 20 \log_{10}\left(\frac{p}{p_0}\right) \text{ dB SPL}$$

其中 $p_0 = 20 \mu\text{Pa}$ 为参考声压（1kHz纯音的平均听阈）。

| 声压级 | 典型场景 |
| :--- | :--- |
| 0 dB SPL | 听阈 |
| 30 dB | 安静图书馆 |
| 60 dB | 正常对话 |
| 85 dB | 长期暴露损伤阈值 |
| 120 dB | 摇滚演唱会/电锯 |
| 140 dB | 喷气发动机近距/痛阈 |

## 二、数学层：如何描述声音

### 1. 傅里叶分析——声音理论的基石

**核心定理：** 任何周期性信号都可以分解为一系列正弦波的叠加。

$$x(t) = \sum_{n=1}^{\infty} A_n \sin(2\pi n f_0 t + \phi_n)$$

- $f_0$ = 基频（决定音高）
- $n f_0$ = 第n次谐波/泛音
- $A_n$ = 各谐波振幅（决定音色）
- $\phi_n$ = 各谐波相位

> 🔑 **这意味着：** "音色"在数学上就是**频谱包络的形状**。小提琴和长笛演奏同一个A4(440Hz)，基频相同，但谐波振幅分布完全不同。

### 2. 时域 vs 频域 vs 时频域

| 表示方式 | 工具 | 优势 | 局限 |
| :--- | :--- | :--- | :--- |
| 时域波形 | 示波器 | 直观看瞬态、包络 | 看不出频率成分 |
| 频谱 | FFT | 精确看频率组成 | 丢失时间信息 |
| 时频图 | STFT/小波 | 同时看频率随时间的变化 | 受不确定性原理限制 |

#### 海森堡不确定性原理（声学版）
$$\Delta t \cdot \Delta f \geq \frac{1}{4\pi}$$

时间分辨率和频率分辨率**不可兼得**。窗口越短→时间精但频率糊；窗口越长→频率精但时间糊。这是所有音频分析的固有极限，不是技术缺陷。

## 三、感知层

### 1. 等响曲线与频率加权

人耳对不同频率的灵敏度**极不均匀**：

- 最敏感区间：2-5 kHz（外耳道共振+中耳传递函数共同作用）
- 低频和高频需要更高的声压才能达到相同响度
- 这种不均匀性**随音量变化**：大音量时趋于平坦，小音量时中频突出更明显

这就是**等响曲线（ISO 226）** 的含义，也是为什么：
- 音响有"Loudness"补偿按钮
- 噪声测量用 dBA（A加权模拟人耳响应）而非线性 dB
- 混音时不能只在小音量下判断低频

### 2. 音高的非线性

| 物理尺度 | 感知尺度 | 关系 |
| :--- | :--- | :--- |
| 频率 (Hz) | 音高 (Mel/Bark) | 近似对数 |
| 440 Hz → 880 Hz | A4 → A5 | 感知为"一个八度" |
| 880 Hz → 1760 Hz | A5 → A6 | 同样是"一个八度" |

**Mel 刻度**：1000 Mel 定义为 1kHz/40dB SPL 纯音的音高。频率翻倍≠音高翻倍，但在 Mel 刻度上近似线性。

**Bark 刻度**：基于临界带宽，将听觉频率轴划分为约24个 Bark 带。同一 Bark 带内的频率会被听觉系统"融合"处理，这是掩蔽效应的生理基础。

### 3. 掩蔽效应

一个声音的存在会使另一个声音变得不可闻：

- **频域掩蔽**：强信号会掩蔽其附近频率的弱信号（向上掩蔽 > 向下掩蔽）
- **时域掩蔽**：强信号之前的短暂时间内（前向掩蔽 ~20ms）和之后较长时间内（后向掩蔽 ~100-200ms）弱信号被掩蔽
- **应用**：MP3/AAC 等有损编码的核心原理——把被掩蔽的信号分量丢弃，人耳察觉不到

### 4. 听觉场景分析

大脑不是被动接收声音，而是主动**组织**声音流：

- **格式塔原则**：相近的频率/时间/空间位置的声音被归为同一声源
- **鸡尾酒会效应**：在嘈杂环境中聚焦单一声源的能力
- **缺失基频现象**：即使基频被滤除，只要谐波序列完整，大脑仍会"脑补"出正确的音高


## 四、空间听觉：我们如何定位声音

### 双耳线索

| 线索 | 有效频段 | 机制 |
| :--- | :--- | :--- |
| ITD（双耳时间差） | < 1500 Hz | 波长 > 头宽，相位差可解 |
| ILD（双耳强度差） | > 1500 Hz | 头部遮挡造成阴影效应 |
| HRTF（头相关传递函数） | 全频段 | 耳廓/头部/躯干的滤波提供仰角和前/后分辨 |

> 🔑 **HRTF 是关键**：ITD/ILD 只能给出水平面上的圆锥定位，无法区分前后和上下。耳廓的复杂褶皱对来自不同仰角的声音施加了独特的频谱修饰，大脑通过学习这些修饰来实现三维定位。这也是为什么耳机虚拟环绕声效果因人而异——每个人的耳廓形状不同，HRTF 也不同。


## 五、数字层：声音的数字化

### 1. 采样定理（Nyquist-Shannon）

$$f_s \geq 2 f_{max}$$

要无失真地数字化带宽为 $f_{max}$ 的信号，采样率至少为 $2f_{max}$。

- CD标准：44.1kHz → 可还原 ≤22.05kHz（覆盖人耳上限~20kHz）
- 专业音频：48k/96k/192kHz
- 低于 Nyquist 频率的成分会产生**混叠（Aliasing）**，必须在采样前用抗混叠滤波器切除

### 2.量化 (Quantization)

采样解决了**时间上的离散化**（每隔多久取一个点），而量化解决的是**幅度上的离散化**（每个点的值用多少级台阶来表示）。

现实世界的信号幅度是连续的（无穷多个可能值），但数字系统只能用有限个整数来表示。量化就是**把连续的幅度值“四舍五入”到最接近的可用数字级别**。

```text
连续幅度          量化后（3-bit，8级台阶）
   │                    ┌───┐
   │                 ┌──┘   └──┐
   │              ┌──┘         └──┐
   │           ┌──┘               └──┐
   │        ┌──┘                     └──┐
   │     ┌──┘                           └──┐
   │  ┌──┘                                 └──┐
   └──────────────────────────────────────────→ 时间
```

#### 关键参数：位深度 (Bit Depth)
-   **n bit** 的量化 → 有 $2^n$ 个可用级别
-   8 bit → 256 级
-   16 bit → 65,536 级（CD标准）
-   24 bit → 16,777,216 级（专业录音）

#### 量化误差与量化噪声
量化本质上是一种**有损近似**。真实值与量化值之间的差值就是**量化误差**，它在听感上表现为底层的**量化噪声**（类似轻微的嘶嘶声）。

> ⚠️ 量化噪声是数字系统的**固有底噪**，无法完全消除，只能通过增加位深度来压低。

### 2. 动态范围 (Dynamic Range)

#### 是什么？
动态范围是指一个系统能够**无失真地处理的最大信号与最小可分辨信号之间的比值**，通常用 **dB** 表示。

$$DR_{dB} = 20 \log_{10}\left(\frac{A_{max}}{A_{min}}\right)$$

-   **$A_{max}$**：系统能承载的最大不失真幅度（满量程，Full Scale）
-   **$A_{min}$**：系统能分辨的最小有效信号（通常受限于量化噪声或模拟电路本底噪声）
