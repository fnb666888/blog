# AI 绘画提示词指南

一个比较完整的提示词通常包含以下几个部分，你可以把它想象成一个"配方"：

> **主体 + 细节 + 环境/背景 + 风格/媒介 + 构图/视角 + 光照 + 质量/参数**

## 一、经典绘画风格

这类风格模仿传统的绘画媒介和艺术流派，强调笔触和质感。

### 绘画流派

- **油画 (Oil Painting)**：材质厚重，笔触浓烈，适合古典、写实或厚重的历史题材。
- **水彩 (Watercolor)**：清新、透明、灵动，适合表现轻盈的风景或少女感的画面。
- **印象派 (Impressionism)**：捕捉光线的瞬间，笔触可见，色彩未混合，充满光影感。
- **梵高/后印象派**：情感张力强，线条粗犷，色彩对比强。
- **水墨/国画**：泼墨、留白、黑白为主，极具东方神韵。
- **涂鸦 (Doodle)**：随性的线条，手绘感强，适合童趣或街头风格。
- **版画/木刻 (Woodcut)**：线条刚劲，黑白对比强烈。

## 二、数字科技与动漫风格

- **皮克斯/3D 卡通 (Pixar/Clay)**：立体造型，生动表情。
- **赛博朋克 (Cyberpunk)**：高科技低生活，霓虹灯（红蓝紫），雨夜，机械义肢，未来都市。
- **蒸汽朋克 (Steampunk)**：维多利亚时代的复古机械，黄铜色，齿轮，蒸汽技术。
- **吉卜力/宫崎骏 (Ghibli)**：梦幻、手绘感、温暖的色调，像《龙猫》或《哈尔的移动城堡》。
- **新海诚风格**：极致的光影，细腻的背景，天空和云彩非常美。
- **Q版/萌系**：头大身小，比例夸张，可爱风。
- **迪士尼 (Disney)**：浪漫、魔幻、童话感，角色设计圆润可爱。
- **辛普森/美式卡通**：色彩浓烈，线条粗犷。

## 三、设计风格

- **像素风 (Pixel Art)**：像马赛克一样的方块像素，8-bit 或 16-bit 游戏感，非常有怀旧情怀。
- **低多边形 (Low Poly)**：由简单的多边形构成，带有科技感和几何美感。
- **波普艺术 (Pop Art)**：色彩鲜艳，大面积平涂，有印刷网点感，视觉冲击力强。
- **包豪斯 (Bauhaus)**：德国风格，几何形状，简洁，强调功能性和抽象色彩。
- **扁平风 (Flat Design)**：去除多余的透视和纹理，极简，常用于 App 图标或 UI 设计。
- **弥散渐变 (Gradient)**：柔和的色彩过渡，现代、高级、有氛围感。
- **超现实主义 (Surrealism)**：像达利或玛格丽特的作品，不合逻辑的物体组合，梦幻感。
- **故障艺术 (Glitch Art)**：模拟数据出错的效果，RGB 分离，像素错位，赛博感十足。
- **抽象/几何**：不具象，由色块、线条和几何图形构成。

## 四、写实摄影风

- **胶片摄影**：模拟柯达、富士等胶片的色彩颗粒感。
- **特定镜头**：如"长焦镜头"、"微距摄影"、"鱼眼镜头"。
- **特定光效**：如"丁达尔效应"、"霓虹灯反射"、"CCTV 监控视角"。

## 如何使用这些风格词？

1. **组合拳**：不要只用一个词。比如你想画一个中国风的赛博朋克，可以写：`赛博朋克，机械义肢，古风少女，霓虹灯光，中国山水画背景`。

2. **权重控制**：如果你想要某种风格更强烈，可以加括号强调。例如：`(水墨画风格:1.3)`。

3. **混搭创新**：最有趣的往往是混搭。比如"乐高风格的梵高自画像"或者"赛博朋克版的清明上河图"。
