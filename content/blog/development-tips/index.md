# 开发小知识

## 基础概念

前后端分离、包管理器、日志系统、错误处理、缓存机制、并发控制。

## Web 应用框架

| 框架 | 特点 |
|------|------|
| **Streamlit** | 易上手，不需要前端知识 |
| **Gradio** | 快速生成前端交互 |
| **Flask** | 微框架，按需扩展，核心是路由和模板，其他靠第三方插件，适合小型应用 |
| **Django** | 重量级框架，全功能，适合中大型应用 |
| **FastAPI** | 支持异步编程，性能极高 |
| **Express** | Node.js 后端框架 |
| **Spring** | Java 企业级框架 |
| **Next** | React 全栈框架 |

## 代理

| 类型 | 说明 |
|------|------|
| **HTTP 代理** | 可以解析并可能修改/缓存内容 |
| **Socks5 代理** | 原封不动转发数据 |

## 网络协议

| 协议 | 特点 |
|------|------|
| **UDP** | 不需要建立连接，直接发送数据，对方可能收不到，不稳定，速度快 |
| **TCP** | 需要三次握手建立连接，稳定 |

## 网络基础

| 概念 | 说明 |
|------|------|
| **IPv6** | 128 位地址，8 组 16 进制数字 |
| **IPv4** | 32 位地址，4 组十进制数字 |
| **子网掩码** | 判断设备是否位于内网中 |
| **CDN** | 内容分发网络 |
| **DDoS** | 分布式拒绝服务攻击，网络暴力攻击 |
| **SaaS** | 软件即服务 |

## 通信方式

| 协议 | 特点 |
|------|------|
| **WebSocket** | 双向通信，长连接 |
| **Webhook** | 单向通信，需要公网 IP，事件触发 |

## 远程工具

| 工具 | 说明 |
|------|------|
| **VNC** | 跨平台图形桌面共享系统 |
| `man` / `--help` | 查询 Linux 命令的用法 |

## 静态站点生成器

| 工具 | 特点 |
|------|------|
| **Hugo** | Go 语言，适合文章量大，追求效率 |
| **VitePress** | Vue 3，构建快 |
| **Hexo** | 国内生态好，插件丰富 |
| **Next.js** | React 生态强，扩展性高 |
| **Astro** | 默认 0 JS，加载速度极快 |
