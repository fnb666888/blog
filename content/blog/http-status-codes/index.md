# HTTP 状态码速查

## 1xx（信息性状态码）

请求已接收，继续处理。

| 状态码 | 名称 | 说明 |
|--------|------|------|
| 100 | Continue | 服务器已收到请求头，客户端可以继续发送请求体 |

## 2xx（成功状态码）

请求已成功被服务器接收、理解并接受。

| 状态码 | 名称 | 说明 |
|--------|------|------|
| 200 | OK | 最常见的成功状态码，表示请求已成功处理 |
| 201 | Created | 请求成功并且服务器创建了新的资源（例如上传了一个新模型） |
| 204 | No Content | 请求成功，但响应报文中不包含任何实体内容 |

## 3xx（重定向状态码）

需要进一步操作以完成请求。

| 状态码 | 名称 | 说明 |
|--------|------|------|
| 301 | Moved Permanently | 永久重定向。请求的资源已永久移动到新位置 |
| 302 | Found | 临时重定向。请求的资源临时从不同的 URI 响应 |
| 304 | Not Modified | 资源未修改。客户端可以使用缓存的版本，无需重新下载 |

## 4xx（客户端错误状态码）

请求包含语法错误或无法完成。

| 状态码 | 名称 | 说明 |
|--------|------|------|
| 400 | Bad Request | 请求语法错误，服务器无法理解 |
| 401 | Unauthorized | 未授权。需要身份验证才能访问该资源 |
| 403 | Forbidden | 禁止访问。服务器理解了请求，但拒绝执行（通常是因为权限不足） |
| 404 | Not Found | 未找到。请求的资源不存在（例如模型名称拼写错误） |
| 429 | Too Many Requests | 请求过多。你在短时间内发送了太多请求，触发了速率限制 |

## 5xx（服务器错误状态码）

服务器在处理请求时发生错误。

| 状态码 | 名称 | 说明 |
|--------|------|------|
| 500 | Internal Server Error | 服务器内部错误。服务器遇到了意外情况，无法完成请求 |
| 502 | Bad Gateway | 网关错误。作为网关或代理的服务器从上游服务器收到了无效响应 |
| 503 | Service Unavailable | 服务不可用。服务器暂时无法处理请求，通常是因为过载或维护 |
| 504 | Gateway Timeout | 网关超时。作为网关或代理的服务器未能及时从上游服务器收到响应 |
