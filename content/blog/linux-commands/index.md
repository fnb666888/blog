# Linux 命令速查

## 📁 文件与目录操作

| 命令 | 说明 |
|------|------|
| `ls` | 列出目录内容 |
| `ls -a` | 列出所有文件（含隐藏） |
| `cd` | 切换目录 |
| `pwd` | 显示当前目录路径 |
| `mkdir` | 创建目录 |
| `rm` | 删除文件 |
| `rm -r` | 递归删除目录 |
| `cp 源 目标` | 复制文件或目录 |
| `mv 源 目标` | 移动/重命名文件 |
| `touch 文件` | 创建空文件或更新时间戳 |

## 📄 查看和编辑文件

| 命令 | 说明 |
|------|------|
| `cat 文件` | 查看文件内容 |
| `less 文件` | 分页查看文件 |
| `head -n 文件` | 查看文件前 n 行 |
| `tail -n 文件` | 查看文件后 n 行 |
| `vim 文件` | 交互式文本编辑器 |
| `nano 文件` | 简易文本编辑器，有快捷键 |

**Vim 模式说明：**
- 普通模式（默认）：移动光标，删除，复制，粘贴，保存退出
- 插入模式：按 `i` 进入；`Esc` 退出
- 命令行模式：`:wq` 保存退出，`:q!` 不保存退出

## 🔍 查找与搜索

| 命令 | 说明 |
|------|------|
| `find 路径 -name 文件名` | 查找文件 |
| `grep "关键词" 文件` | 在文件中搜索内容 |
| `grep -r "关键词" 目录` | 递归搜索 |

## 📦 权限与用户

| 命令 | 说明 |
|------|------|
| `chmod 权限 文件` | 修改文件权限（rwx，3种用户：u,g,o） |
| `chown 用户:组 文件` | 修改文件拥有者 |
| `sudo 命令` | 以管理员权限执行 |
| `passwd` | 修改密码 |
| `whoami` | 查看当前用户 |

## 🌐 网络相关

| 命令 | 说明 |
|------|------|
| `ping 地址` | 测试网络连通性（不需要 http） |
| `curl 地址` | 发送 HTTP 请求 |
| `wget 地址` | 下载文件 |
| `netstat -tunlp` | 查看网络连接和端口 |
| `ss -tunlp` | 更现代的 netstat 替代 |

## 🧠 进程与系统信息

| 命令 | 说明 |
|------|------|
| `ps` | 查看进程 |
| `top / htop` | 实时查看进程和资源占用 |
| `kill PID` | 终止进程 |
| `df -h` | 磁盘使用情况 |
| `du -sh 目录` | 目录大小 |
| `free -h` | 内存使用情况 |
| `uname -a` | 系统信息 |

## 📦 压缩与解压

| 命令 | 说明 |
|------|------|
| `tar -czvf 包.tar.gz 目录` | 打包并压缩 |
| `tar -xzvf 包.tar.gz` | 解压 |
| `zip / unzip` | zip 压缩 |

## 🔧 其他实用命令

| 命令 | 说明 |
|------|------|
| `history` | 查看命令历史 |
| `alias` | 查看或设置命令别名 |
| `date` | 查看日期时间 |
| `echo 内容` | 输出内容 |
| `man 命令` | 查看命令手册 |

## 📂 Shell 配置文件

| 文件 | 说明 |
|------|------|
| `.bashrc` | 设置别名、环境变量、PATH，每次打开终端自动加载 |
| `.bash_profile` | 远程登录时加载 |

## 📂 常用目录说明

| 目录 | 说明 |
|------|------|
| `/etc` | 系统和应用程序的配置文件 |
| `/var` | 集中管理系统和服务的运行时数据（日志、缓存、任务队列） |
| `/tmp` | 临时文件，系统重启会自动清空 |
| `/usr` | 存放系统软件、库文件、第三方软件本体 |
| `/boot` | 启动系统的文件 |
| `/home` | 普通用户的家目录 |
| `/root` | 超级管理员的家目录 |
| `/dev` | 存放所有设备的文件，例如硬盘 |
| `/proc` | 映射内存中的内核和进程信息 |
| `/mnt` 和 `/media` | 用于挂载临时文件系统 |
