# Markdown 常用标记速查

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 文本格式

| 语法 | 效果 |
|------|------|
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |

## 分割线

```markdown
---
```

## 列表

### 无序列表

```markdown
- 项目一
- 项目二
  - 子项目
```

### 有序列表

```markdown
1. 第一步
2. 第二步
3. 第三步
```

## 链接与图片

| 语法 | 说明 |
|------|------|
| `[文本](https://url)` | 超链接 |
| `![图片描述](图片链接)` | 图片 |

## 表格

```markdown
| 列1 | 列2 | 列3 |
| --- | --- | --- |
| A   | B   | C   |
```

## 代码块

````markdown
```语言
代码内容
```
````

示例：

````markdown
```python
print("Hello World")
```
````
