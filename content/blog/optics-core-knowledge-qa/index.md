# 第1章 光的干涉 —— 基础知识详解

## 1.1 波动的独立性、叠加性和相干性

### 一、波动的独立性（独立传播原理）

几列波在同一介质中传播时，无论它们是否相遇，**每一列波都保持自己原有的特性**（频率、波长、振幅、振动方向、传播方向）不变，就像其他波不存在一样。

独立性是叠加原理成立的前提描述之一：波相遇时"互不干扰地各自传播"。

### 二、波动的叠加性（叠加原理）

当几列波在空间某点相遇时，该点的**合振动等于各列波单独存在时在该点引起的振动的矢量和**：

$$\vec{E}(P,t) = \vec{E}_1(P,t) + \vec{E}_2(P,t) + \cdots$$

对光波（电磁波）而言，叠加的是电场强度矢量（光矢量）。叠加原理成立的条件是**波的强度不太大**（线性介质）。在强光（如激光聚焦）下介质出现非线性效应时，叠加原理不再严格成立，那就是非线性光学的范畴。

**关键推论**：叠加是"振动的叠加"而不是"强度的叠加"。合强度一般不等于各强度之和：

$$I = I_1 + I_2 + 2\sqrt{I_1 I_2}\,\overline{\cos\delta}$$

其中 $\delta$ 是两波在该点的相位差，横线表示对观测时间取平均。正是交叉项 $2\sqrt{I_1I_2}\,\overline{\cos\delta}$ 的存在，使叠加后空间各点强度重新分布——有的地方加强、有的地方减弱——这就是干涉。

### 三、相干性与相干条件

**干涉现象**：两束光在空间叠加时，合强度在空间各点**稳定地**出现强弱分布（明暗条纹）的现象。

设两束同频率、同振动方向的单色光在 P 点的光振动为
$$E_1 = A_1\cos(\omega t + \varphi_1),\quad E_2 = A_2\cos(\omega t + \varphi_2)$$
叠加后合振幅满足
$$A^2 = A_1^2 + A_2^2 + 2A_1A_2\cos\delta,\qquad \delta = \varphi_2 - \varphi_1$$
强度正比于振幅平方，故
$$I = I_1 + I_2 + 2\sqrt{I_1I_2}\cos\delta$$

- 当 $\delta = 2k\pi$（$k=0,\pm1,\pm2,\cdots$）时，$I_{max} = (\sqrt{I_1}+\sqrt{I_2})^2$，**干涉相长（明）**；
- 当 $\delta = (2k+1)\pi$ 时，$I_{min} = (\sqrt{I_1}-\sqrt{I_2})^2$，**干涉相消（暗）**；特别当 $I_1=I_2$ 时暗点强度为零，明点强度为单束的 4 倍。

但是 ordinary 光源（如两只独立灯泡）发出的光，其相位差 $\delta$ 在观测时间内（人眼约 0.1 s，探测器响应时间更长）以约 $10^{-8}$ s 的量级随机跳变，$\overline{\cos\delta}=0$，于是 $I = I_1+I_2$，只看到均匀亮度——**非相干叠加**。

因此**相干条件**为：两束光必须满足
1. **频率相同**；
2. **振动方向相同（或有不平行的分量）**；
3. **相位差恒定**（在观测时间内保持不变）。

满足相干条件的光称为**相干光**。由于普通光源发光是原子逐次随机辐射的波列（长约几米以内），两独立光源不可能相干；**获得相干光的唯一办法是把同一光源同一点发出的光波"一分为二"**，让它们经过不同路径后再相遇——这就是分波面法与分振幅法（见 1.3、1.6、1.7）。

## 1.2 由单色波叠加所形成的干涉图样

### 一、两个点光源的干涉图样

设真空中（或均匀介质中）有两个相干单色点光源 $S_1$、$S_2$，相距为 $d$。空间任一点 P 到两源的距离为 $r_1$、$r_2$，则两波在 P 点的相位差为

$$\delta = \frac{2\pi}{\lambda}(r_2 - r_1) + (\varphi_{02}-\varphi_{01})$$

若两源初相相同，则 $\delta = \dfrac{2\pi}{\lambda}\Delta$，其中 $\Delta = r_2-r_1$ 为**光程差**（真空中即波程差）。

- 明点条件：$\Delta = k\lambda$
- 暗点条件：$\Delta = \left(k+\tfrac12\right)\lambda$

到两定点距离之差为常数的点的轨迹是**以 $S_1S_2$ 为轴的双叶旋转双曲面**，所以干涉加强点与减弱点分别构成一族族交替的双曲面；用屏去截取，就得到明暗相间的**干涉条纹**（双曲线族或近似直线条纹）。这就是"干涉图样"的几何本质：**条纹是等光程差面与观察面的交线**。

### 二、光程与光程差

光在折射率 $n$ 的介质中波长变为 $\lambda' = \lambda/n$，走过几何路程 $r$ 相当于真空中走过 $nr$。定义**光程** $L = nr$，**光程差** $\Delta = L_2 - L_1$。相位差与光程差的普遍关系为

$$\delta = \frac{2\pi}{\lambda}\Delta \quad(\lambda \text{为真空波长})$$

引入光程的好处：把介质中的传播问题折算成真空中的等效路程，相位差只由光程差决定。

### 三、条纹形状与定域性

干涉图样的形状取决于观察方式：
- 用屏接收双曲面族，得到**双曲线条纹**；在远场（$r\gg d$）近似下条纹近似为等间距的平行直条纹；
- 若两相干波是**平面波**，叠加后得到一组等间距平行平面状的强弱层，屏上为平行直条纹，条纹间距 $e = \dfrac{\lambda}{2\sin(\theta/2)} \approx \dfrac{\lambda}{\theta}$（$\theta$ 为两波传播方向夹角）；
- 若两波是**球面波与平面波**或会聚球面波，则得到同心圆环条纹。

这些结论为后面杨氏条纹、等倾圆环、等厚直条纹、牛顿环等具体图样提供了统一的判据：**先求光程差 $\Delta$ 的表达式，再令 $\Delta=k\lambda$ 或 $(k+\frac12)\lambda$ 即得明暗条纹的分布规律**。

## 1.3 分波面双光束干涉

"分波面"：从同一波前的不同部位截取两部分作为相干光源。典型装置如下。

### 一、杨氏双缝干涉（Young, 1801）

单色光先经狭缝 S（线光源）形成柱面波，再照射到相距 $d$ 的双缝 $S_1、S_2$ 上，$S_1、S_2$ 处于同一波面上，因而是相干光源。在距离 $D$（$D\gg d$）的屏上观察。

屏上距中心 O 为 $x$ 的点 P，光程差近似为
$$\Delta = r_2 - r_1 \approx d\sin\theta \approx d\,\frac{x}{D}$$

- 明纹：$x_k = \pm k\dfrac{D}{d}\lambda,\quad k=0,1,2,\cdots$
- 暗纹：$x = \pm(2k+1)\dfrac{D}{2d}\lambda$
- **条纹间距**：
$$\Delta x = \frac{D}{d}\lambda$$

特点：条纹等间距、等亮度（近似），中央为明纹；用白光照射时中央为白色亮纹、两侧为彩色条纹（因 $\Delta x\propto\lambda$，紫光条纹密、红光疏）。杨氏实验首次测定了光波长，是光波动说的决定性证据。由 $\Delta x$ 的测量可反求波长：$\lambda = \dfrac{d}{D}\Delta x$。

### 二、菲涅耳双面镜

两块夹角 $\alpha$ 极小（约几十分）的平面镜 $M_1、M_2$，狭缝光源 S 经两镜分别成虚像 $S_1、S_2$，二者即为一对相干光源，间距 $d \approx 2r\alpha$（$r$ 为 S 到镜交线的距离）。在两虚像波面重叠区域内可看到干涉条纹，条纹间距公式与杨氏相同：$\Delta x = \dfrac{D}{d}\lambda$（$D$ 为虚像平面到屏的距离）。遮光板用来挡住 S 直接射向屏的光。

### 三、菲涅耳双棱镜

顶角接近 $180^\circ$ 的双棱镜把 S 发出的波前折射成两束，等效于两个虚光源 $S_1、S_2$ 发出的相干光，重叠区内产生等间距直条纹，分析方法与双面镜相同。

### 四、洛埃镜（Lloyd's mirror）

光一方面直接射到屏上，另一方面经平面镜掠入射反射后射到屏上；反射光等效于虚光源 S′ 发出。S 与 S′ 构成相干光源对。**重要现象**：把屏移到与镜面接触处，接触点处光程差为零，本应是明纹，实验却观察到**暗纹**——说明反射光与入射光在该点相位相反，即光从光疏介质射向光密介质、在掠入射（及正入射）反射时发生了大小为 $\pi$ 的相位突变， equivalent 于多走（或少走）了半个波长，称为**半波损失**。洛埃镜实验是半波损失的直接实验证据，也是 1.4 附录"额外光程差"概念的来源。

### 五、维纳驻波实验（补充说明光矢量是电场矢量）

单色光垂直入射到平面镜上，入射波与反射波叠加形成**驻波**；把与镜面成微小夹角的感光胶片放入，显影后出现等间距黑带（波腹处感光强），测得相邻波腹间距为 $\lambda/2$。实验还证明：对感光片和视网膜起作用的是**电场矢量 E**（电矢量称为光矢量），磁场矢量几乎不起作用。这为"叠加时只叠加电矢量"提供了依据。

## 1.4 干涉条纹的可见度 · 光波的时间相干性和空间相干性

### 一、可见度（对比度、衬比度）的定义

$$V = \frac{I_{max} - I_{min}}{I_{max} + I_{min}}$$

$V=1$ 时明暗对比最清晰（要求 $I_1=I_2$）；$V=0$ 时条纹消失。由 $I_{max/min} = I_1+I_2 \pm 2\sqrt{I_1I_2}\,|\overline{\cos\delta}|$ 可知，可见度受三方面因素影响：**两束光的振幅比、光源的非单色性、光源的宽度**。

### 二、振幅比的影响

若 $I_1 \ne I_2$，设 $I_2/I_1 = a$，则 $V = \dfrac{2\sqrt{a}}{1+a}$。例如 $a=1$ 时 $V=1$；$a=10$ 时 $V\approx 0.57$。所以干涉装置应尽量使两束光强度接近。

### 三、时间相干性（光源非单色性的影响）

实际"单色光"总有一定**谱线宽度** $\Delta\lambda$（波列长度有限）。每个波长成分各自形成一套条纹，间距正比于 $\lambda$；级次 $k$ 越高，不同波长的明纹错开越严重。当第 $k$ 级 $\lambda+\Delta\lambda$ 的明纹与第 $k+1$ 级 $\lambda$ 的明纹重合时，条纹完全模糊：

$$(k+1)\lambda = k(\lambda+\Delta\lambda)\ \Rightarrow\ k = \frac{\lambda}{\Delta\lambda}$$

对应的最大光程差称为**相干长度**：

$$\Delta_{max} = k\lambda = \frac{\lambda^2}{\Delta\lambda}$$

由波列观点：相干长度就是**波列长度** $L_0 \approx c\,\Delta t$（$\Delta t$ 为每次发光的持续时间），相应的**相干时间** $\Delta t = \dfrac{\Delta_{max}}{c} = \dfrac{1}{\Delta\nu}$。只有当两束光的光程差小于相干长度时才能观察到干涉——这就是**时间相干性**。例如钠灯 $\Delta\lambda$ 较小，相干长度约几毫米； He-Ne 激光单色性极好，相干长度可达几十米；白光 $\Delta\lambda$ 很大，相干长度仅约微米量级，故白光干涉只能看到零级附近寥寥几条彩色条纹。

### 四、空间相干性（光源宽度的影响）

以杨氏实验为例：若把入射狭缝 S 加宽为宽度 $b$ 的扩展光源，可把它看作许多互不相干的线光源的集合，每一线光源在屏上产生一套位置略有偏移的条纹（偏移量正比于该线光源的横向位置）。当光源边缘两点产生的条纹错开恰好一个条纹间距时，屏上条纹消失。由此得临界宽度

$$b_0 = \frac{\lambda}{\theta} = \frac{R\lambda}{d}$$

其中 $\theta = d/R$ 是双缝对光源中心的张角，$R$ 为光源到双缝屏的距离。实际要求 $b < b_0$（通常取 $b \lesssim b_0/4$）才能看清条纹。

更一般的表述：横向距离为 $d$ 的两点处光振动能够相干的程度，由**空间相干范围**描述：

$$d < \frac{\lambda}{\theta}\quad(\theta \text{为光源的角宽度})$$

即：**光源角宽度越大，空间相干范围越小**；双星干涉仪（迈克耳孙测星仪）正是利用"条纹第一次消失时的双镜间距 $d$"来测量恒星角直径 $\theta = \lambda/d$ 的。

### 五、小结

- **时间相干性**源于发光的时间间歇性（波列有限长），限制**光程差**（纵向相干长度 $\lambda^2/\Delta\lambda$）；
- **空间相干性**源于光源的横向扩展，限制**相干孔径/光束间距**（$\lambda/\theta$）；
- 两者共同决定条纹可见度，是设计任何干涉仪时必须核算的指标。

## *1.5 菲涅耳公式

菲涅耳公式给出光在两种介质分界面上**反射波、折射波与入射波的振幅比和相位关系**，是讨论反射/折射时是否有半波损失、以及薄膜干涉中振幅分配的基础。

### 一、设定

光从折射率 $n_1$ 的介质以入射角 $i_1$ 射向 $n_2$ 的介质，折射角 $i_2$，满足 $n_1\sin i_1 = n_2 \sin i_2$。把电矢量分解为：
- **s 分量**：垂直于入射面；
- **p 分量**：平行于入射面。

### 二、公式（振幅反射比与透射比）

$$r_s = \frac{E_{1s}'}{E_{1s}} = -\frac{\sin(i_1-i_2)}{\sin(i_1+i_2)},\qquad t_s = \frac{E_{2s}}{E_{1s}} = \frac{2\sin i_2\cos i_1}{\sin(i_1+i_2)}$$

$$r_p = \frac{E_{1p}'}{E_{1p}} = \frac{\tan(i_1-i_2)}{\tan(i_1+i_2)},\qquad t_p = \frac{E_{2p}}{E_{1p}} = \frac{2\sin i_2\cos i_1}{\sin(i_1+i_2)\cos(i_1-i_2)}$$

### 三、物理结论

1. **半波损失的判据**：正入射（$i_1\to 0$）时，$r = \dfrac{n_1-n_2}{n_1+n_2}$（适当约定下）。当光从光疏射向光密（$n_2>n_1$）反射时 $r<0$，表示反射光电矢量与入射光反向，即发生 $\pi$ 的相位突变（半波损失）；从光密到光密则无相位突变。这解释了洛埃镜与薄膜干涉中的"额外光程差 $\lambda/2$"。
2. **布儒斯特角**：当 $i_1+i_2 = 90^\circ$ 时 $r_p = 0$，反射光为完全 s 偏振光，此时 $\tan i_B = n_2/n_1$。
3. **能量关系**：由能流守恒可得反射率 $R$ 与透射率 $T$（$R+T=1$），正入射时 $R = \left(\dfrac{n_1-n_2}{n_1+n_2}\right)^2$。例如空气—玻璃界面 $R\approx 4\%$，这是增透膜问题的出发点（见"视窗与链接：增透膜与高反射膜"）。
4. 菲涅耳公式还说明：薄膜上下表面两反射光的**振幅比**由界面反射率决定，因此分振幅干涉中两束光振幅接近、可见度好。

（公式的详细推导见附录 1.3，基于边界上电磁场切向分量连续的条件。）

## 1.6 分振幅薄膜干涉（一）——等倾干涉

"分振幅"：利用薄膜两个表面对入射光的**多次反射与透射**，把同一束光的振幅分成若干部分，再使其相遇干涉。

### 一、光程差公式

折射率 $n$、厚度 $e$ 的均匀薄膜，置于折射率 $n_1$ 的环境中，扩展光源的光以入射角 $i$ 射到膜上，经上、下表面反射得到两束平行光，经透镜会聚于一点 P 干涉。可以证明（含几何路程差与可能的半波损失）：

$$\Delta = 2e\sqrt{n^2 - n_1^2\sin^2 i} + \Delta'$$

其中 $\Delta'$ 为**额外光程差**：若两反射面中只有一个发生半波损失（如空气—膜—空气，或膜两侧介质折射率一大一小夹膜），则 $\Delta' = \lambda/2$；若两界面反射性质相同（都从疏到密或都从密到疏），则 $\Delta'=0$。

明暗条件：
$$\Delta = k\lambda \ \text{（明）};\qquad \Delta = (2k+1)\frac{\lambda}{2}\ \text{（暗）}$$

### 二、等倾条纹的特点

对**厚度均匀**的薄膜，$\Delta$ 只随入射角 $i$ 变化：**倾角相同的光线具有相同的光程差**，故称等倾干涉。

- 扩展光源上各点发出的、以相同倾角入射的光，会聚于透镜焦面上**同一圆环**上，因此条纹是以透镜焦点为中心的一组**同心圆环**；
- 中心处 $i=0$，$\Delta = 2ne+\Delta'$ 最大，**级次 k 最高**；越往外（$i$ 越大）级次越低；
- 膜越厚，条纹越密；连续改变 $e$ 时条纹从中心"涌出"或"陷入"（每改变 $\lambda/2n$ 的厚度，中心涌出或陷入一个条纹）——这是迈克耳孙干涉仪测量长度的原理基础；
- 使用扩展光源不仅不降低可见度（等倾条纹定域于无穷远/透镜焦面），反而使条纹更亮——这是等倾干涉的重要优点。

应用：激光谐振腔选模、薄膜厚度与折射率测量、法布里-珀罗标准具的前身等。

## 1.7 分振幅薄膜干涉（二）——等厚干涉

### 一、条件与光程差

当薄膜**厚度 e 不均匀**（如劈尖、楔形膜），且光近似垂直入射（$i\approx 0$）时，光程差主要取决于该处的厚度：

$$\Delta = 2n\,e(x,y) + \Delta'$$

**厚度相同的地方光程差相同**，干涉条纹即"等厚线"——膜厚相等点的轨迹，条纹**定域在薄膜表面附近**（用显微镜或眼睛调焦于膜面观察）。

明暗条件同上：$\Delta=k\lambda$ 明，$\Delta=(2k+1)\lambda/2$ 暗。

### 二、劈尖（楔形膜）

两平面玻璃片一端夹薄片（或细丝）形成夹角 $\theta$ 极小的空气劈尖（$n=1$），垂直入射单色光。考虑下表面反射的半波损失，$\Delta = 2e + \lambda/2$。

- 棱边处 $e=0$，$\Delta=\lambda/2$，为**暗纹**（半波损失的又一证据）；
- 第 k 级明纹对应 $e_k = (2k-1)\lambda/4$，暗纹对应 $e_k = k\lambda/2$；
- 相邻明（或暗）纹对应的厚度差 $\Delta e = \lambda/2$；
- **条纹间距**：
$$l = \frac{\lambda}{2n\theta}\approx\frac{\lambda}{2\theta}$$
条纹是平行于棱边的等间距直条纹；$\theta$ 越大条纹越密，$\theta$ 过大则条纹密到无法分辨（可见度下降）。

应用：测细丝直径、薄片厚度 $e = N\cdot\lambda/2$（N 为条纹数）；检验光学平面的平整度（条纹弯曲方向与程度反映凹凸，灵敏度达 $\lambda/2$ 量级，即"等厚干涉检平"）。

### 三、牛顿环（概要，详见 1.10）

平凸透镜凸面放在平面玻璃上，形成厚度随半径变化的空气膜：$e \approx r^2/(2R)$。代入 $\Delta = 2e+\lambda/2$ 得明环、暗环半径：

$$r_{暗} = \sqrt{kR\lambda},\qquad r_{明} = \sqrt{(2k-1)\frac{R\lambda}{2}}\quad(k=1,2,\cdots)$$

中心为暗斑；条纹内疏外密。可用于测透镜曲率半径 R 或波长 λ。

### 四、等厚与等倾的对比

| | 等倾干涉 | 等厚干涉 |
|---|---|---|
| 膜厚 | 均匀 | 不均匀 |
| 决定 Δ 的变量 | 入射角 i | 厚度 e |
| 条纹形状 | 同心圆环 | 等厚线（直纹/圆环） |
| 条纹定域 | 无穷远（透镜焦面） | 膜面附近 |
| 光源 | 扩展光源有利 | 宜用平行光/点光源扩展小 |

## 视窗与链接：昆虫翅膀上的彩色

蝴蝶翅膀、蝉翼、甲虫外壳以及肥皂膜、水面油膜呈现的绚丽色彩，大多**不是色素色而是结构色**：其表面具有微米/亚微米级的多层薄膜或周期性微结构，白光入射时，满足干涉加强条件 $2ne\cos i_2 + \Delta' = k\lambda$ 的波长被强烈反射。由于倾角 i 变化时加强的波长随之变化，故颜色随观察角度改变（"虹彩"效应）。这既是等倾/等厚干涉的自然例证，也启发了**光子晶体、结构色防伪、仿生显色材料**等技术。

## 1.8 迈克耳孙干涉仪

### 一、结构

光源 S → 分束板 $G_1$（半反半透膜）把光分成两束：
- 束 1：透射 → 固定镜 $M_1$ → 返回 $G_1$ → 反射 → 观察屏 E；
- 束 2：反射 → 可动镜 $M_2$ → 返回 $G_1$ → 透射 → E。

补偿板 $G_2$（与 $G_1$ 同厚同材质）使两束光在玻璃中经过的厚度相同，保证白光干涉时各波长光程差一致。$M_1'$ 为 $M_1$ 经 $G_1$ 所成的虚像，于是两束光的干涉等效于 **$M_1'$ 与 $M_2$ 之间"空气薄膜"** 的薄膜干涉。

### 二、干涉图样

- 当 $M_1'$ 与 $M_2$ **严格平行**时，等效于均匀空气膜 → **等倾圆环条纹**；
- 当二者有微小夹角时，等效于空气劈尖 → **等厚直条纹**；
- 移动 $M_2$（精密丝杠，可读到 $10^{-4}$ mm 量级）改变等效膜厚 $e$：每移动 $\lambda/2$，光程差改变 $\lambda$，视场中**涌出或陷入一个条纹**。计数 N 个条纹移动即得位移
$$\Delta e = N\cdot\frac{\lambda}{2}$$
这是把长度与波长联系起来的经典方法（曾用于定义米）。
- 用**白光**时，因相干长度极短，只有在零光程差附近才能看到少数彩色条纹（中央暗纹或亮纹），用于**定位零光程差**。

### 三、应用

测波长、测微小位移与折射率（在一臂插入气室/介质片，由条纹移动数求 $n$）、谱线精细结构分析（两组波长条纹叠加使可见度周期性变化）；其原理还发展出迈克耳孙测星仪、傅里叶变换光谱仪，以及现代引力波探测的激光干涉仪（LIGO 即巨型迈克耳孙干涉仪）。迈克耳孙-莫雷实验用它否定了"以太风"，为相对论铺路。

## 1.9 法布里-珀罗干涉仪 · 多光束干涉

### 一、结构

两块内表面镀高反射膜（反射率 $R$ 可达 90% 以上）的平行玻璃板 G1、G2，间距 $h$ 可调（干涉仪）或固定（标准具）。光在两高反膜之间**多次反射**，透射出一系列相互平行、振幅按 $\sqrt{R}$ 的幂次递减的相干光束——**多光束干涉**。

### 二、多光束干涉的光强分布

相邻透射光束的光程差 $\Delta = 2nh\cos i_2$，相位差 $\delta = \dfrac{2\pi}{\lambda}\Delta$。把无穷多束透射光复振幅求和（等比级数，见附录 1.5、1.6），得透射光强（艾里公式）：

$$I_T = \frac{I_0}{1 + \dfrac{4R}{(1-R)^2}\sin^2\frac{\delta}{2}} = \frac{I_0}{1+F\sin^2(\delta/2)},\quad F=\frac{4R}{(1-R)^2}$$

### 三、特点

- 当 $\delta = 2k\pi$（即 $2nh\cos i_2 = k\lambda$）时 $I_T = I_0$，**全透射**；偏离时光强急剧下降；
- R 越大，F 越大，透射条纹越**细锐**（亮纹宽度极窄），背景越暗；与双光束的正弦型条纹相比，分辨本领大大提高；
- 条纹仍为等倾同心圆环；
- 主要参数：**自由光谱范围** $\Delta\lambda = \lambda^2/(2nh)$、**精细度** $\mathcal{F} = \pi\sqrt{R}/(1-R)$、分辨本领 $A = k\mathcal{F}$。

### 四、应用

高分辨率光谱分析（氢-氘同位素位移、谱线超精细结构）、激光谐振腔（F-P 腔选纵模）、光学滤波器与标准具、引力波探测腔等。它是"多光束干涉"最成功的器件。

## 1.10 光的干涉应用举例 · 牛顿环

### 一、牛顿环装置与公式

曲率半径 R 的平凸透镜凸面朝下置于平面玻璃上，其间空气膜厚度 $e$ 与环半径 r 的关系（$r\ll R$）：

$$e \approx \frac{r^2}{2R}$$

垂直入射单色光 λ，考虑下表面（光疏→光密）反射的半波损失：

$$\Delta = 2e + \frac{\lambda}{2} = \frac{r^2}{R} + \frac{\lambda}{2}$$

- 暗环：$\dfrac{r_k^2}{R} = k\lambda \Rightarrow r_k = \sqrt{kR\lambda},\ k=0,1,2,\cdots$（中心 k=0 为暗斑）
- 明环：$r_k = \sqrt{(2k-1)\dfrac{R\lambda}{2}},\ k=1,2,\cdots$

条纹**内疏外密**（$r\propto\sqrt{k}$）。

### 二、测量应用

1. **测波长或曲率半径**：为消除中心接触形变带来的误差，采用逐差法测第 m、n 级暗环直径：
$$R = \frac{D_m^2 - D_n^2}{4(m-n)\lambda}\quad\text{或}\quad \lambda = \frac{D_m^2-D_n^2}{4(m-n)R}$$
2. **检验透镜表面质量**：环的规则程度反映球面加工误差。
3. 其他干涉应用举例：增透膜/高反膜设计、干涉滤光片、膜厚监控（镀膜时由条纹计数控制厚度）、激光干涉测长、全息术的基础等。

## 视窗与链接：增透膜与高反射膜

**增透膜（减反射膜）**：在玻璃（$n_g\approx1.5$）表面镀一层折射率 $n=\sqrt{n_g}\approx1.22$（常用 MgF₂，$n=1.38$）的薄膜，使膜上下两反射光振幅接近且干涉相消。取光学厚度为四分之一波长：

$$ne = \frac{\lambda_0}{4}\quad(\text{膜两侧反射均含或均不含半波损失之差为}\ \lambda/2\ \text{时相消})$$

对 $\lambda_0\approx550$ nm 设计时膜呈紫红色（红光与蓝紫反射略多）。单层膜只能对一个波长完全消反射；**多层膜**（如 $\lambda/4$ 高低折射率交替膜系）可实现宽带增透。

**高反射膜**：交替镀 $\lambda/4$ 的高折射率层（如 ZnS, $n\approx2.35$）与低折射率层（如 MgF₂），使各界面反射光**同相叠加**（多光束干涉），反射率可达 99.9% 以上，用于激光腔镜、F-P 标准具反射膜。二者原理相同——都是薄膜干涉中"按需分配振幅与相位"的工程应用。

## 附录 1.1 振动叠加的三种计算方法

1. **三角函数法（解析法）**：直接写 $E = A_1\cos(\omega t+\varphi_1)+A_2\cos(\omega t+\varphi_2)$，利用和差化积或展开合并，得
$$A = \sqrt{A_1^2+A_2^2+2A_1A_2\cos(\varphi_2-\varphi_1)},\quad \tan\varphi = \frac{A_1\sin\varphi_1+A_2\sin\varphi_2}{A_1\cos\varphi_1+A_2\cos\varphi_2}$$
适合两束光的简单叠加。
2. **矢量图解法（振幅矢量法/旋转矢量法）**：把每个简谐振动画成长度等于振幅、与 x 轴夹角等于初相的矢量，以共同角速度 ω 旋转；合振动即矢量和，用平行四边形法则求 A 与 φ。直观、便于多束光定性分析。
3. **复数法（复振幅法）**：写 $\tilde{E} = A e^{i(\omega t+\varphi)}$，取复振幅 $\tilde{A} = Ae^{i\varphi}$ 相加后再取模与辐角；强度 $I = \tilde{A}\tilde{A}^*$。对**多光束等比级数求和**（F-P 干涉）最为方便。三种方法结果一致，按问题繁简选用。

## 附录 1.2 简谐波的表达式 · 复振幅

沿 +x 方向传播的平面简谐波：
$$E(x,t) = A\cos\left[\omega\left(t-\frac{x}{u}\right)+\varphi_0\right] = A\cos(\omega t - kx + \varphi_0),\quad k=\frac{2\pi}{\lambda}=\frac{\omega}{u}$$
复数表示：$E = \mathrm{Re}\{A e^{i(\omega t - kx+\varphi_0)}\}$，定义**复振幅** $\tilde{E}(x) = A e^{i(\varphi_0 - kx)}$，它集中了振幅与空间相位信息；干涉计算中先叠加复振幅、再求 $I=|\sum \tilde{E}|^2$，可避免繁琐的三角运算。光程差对应的相位因子为 $e^{i\frac{2\pi}{\lambda}\Delta}$。

## 附录 1.3 菲涅耳公式的推导

要点：由电磁理论，在分界面上 **E 和 H 的切向分量连续、B 和 D 的法向分量连续**。对 s 分量（E 垂直入射面，全部为切向分量）：
$$E_1 + E_1' = E_2,\quad (H_1 - H_1')\cos i_1 = H_2\cos i_2$$
利用 $H = nE\sqrt{\varepsilon_0/\mu_0}$（非磁介质 $H=nE\cdot$ 常数）消去 H，联立解得 $r_s、t_s$；对 p 分量同理（注意 E 的切向分量要乘 $\cos i$）得 $r_p、t_p$。推导中约定好各矢量的正方向，即可自然得出反射时的符号（相位突变）信息。

## 附录 1.4 额外光程差

当薄膜两侧介质折射率满足 $n_1 < n < n_2$ 或 $n_1 > n > n_2$（膜折射率介于两侧之间，或单调变化）时，上下两界面的反射**要么都有、要么都没有**半波损失，二者相互抵消，$\Delta' = 0$；当膜两侧为"疏—膜—疏"或"密—膜—密"（如空气—油膜—空气、空气—空气劈尖—玻璃中仅一个界面疏→密）时，两反射光中**恰有一束**经历半波损失，需在几何光程差之外附加
$$\Delta' = \frac{\lambda}{2}$$
即"额外光程差"。判断步骤：①列出两反射界面各自的疏密关系；②凡光疏→光密反射记一次 $\lambda/2$；③两次记则抵消、一次记则保留。它是牛顿环中心暗斑、劈尖棱边暗纹、增透膜条件的共同来源。

## 附录 1.5 有关法布里-珀罗干涉仪的（1-38）式的推导

设入射振幅 $A_0$，膜面振幅反射比 $r$、透射比 $t$（$R=r^2,\ T=t^2$，无吸收时 $R+T=1$）。 successive 透射光束复振幅依次为
$$A_0 t t',\quad A_0 t t' r'^2 e^{i\delta},\quad A_0 t t' r'^4 e^{i2\delta},\ \cdots$$
利用 $tt' = 1-r^2 = 1-R$（斯托克斯关系 $r'=-r$），求和得几何级数：
$$\tilde{A}_T = A_0(1-R)\sum_{m=0}^{\infty}(R e^{i\delta})^m = \frac{A_0(1-R)}{1-Re^{i\delta}}$$
取模平方：
$$I_T = \frac{I_0(1-R)^2}{1+R^2-2R\cos\delta} = \frac{I_0}{1+\frac{4R}{(1-R)^2}\sin^2\frac{\delta}{2}}$$
即艾里分布（书中式 1-38）。同理可得反射光强 $I_R = I_0 - I_T$（无吸收时互补）。

## 附录 1.6 有同一相位差的多光束叠加

对 N 束振幅相同（或按等比递减）、相邻相位差均为 δ 的光：用复振幅法
$$\tilde{A} = A\sum_{m=0}^{N-1} e^{im\delta} = A\,\frac{1-e^{iN\delta}}{1-e^{i\delta}}$$
强度
$$I = A^2\frac{\sin^2(N\delta/2)}{\sin^2(\delta/2)}$$
当 $\delta=2k\pi$ 时 $I=N^2A^2$（主极大）；其间出现 N−1 个零点和 N−2 个次极大——这正是多光束干涉条纹比双光束锐利的数学原因，也为衍射光栅的多光束干涉理论打下基础（N→∞ 且含振幅衰减因子时即过渡到 F-P 的艾里公式）。
