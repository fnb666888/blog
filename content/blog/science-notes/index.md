# 科学小问题

## 超导

- **零电阻**：输电、超导磁储能、不发热、产生强磁场
- **完全抗磁性**：磁悬浮

## 纳米技术

在纳米尺度上构建物质，涉及导电性、熔点、材料强度等特性。

## 物理学基础

- **物理研究对象**：物质、力、能量
- **基本作用力**：引力、电磁力、弱相互作用、强相互作用
- **基本粒子**：
  - **费米子（物质粒子）**：夸克（通过强相互作用构成中子和质子）、轻子（不参与强相互作用）
  - **玻色子（传递力）**：光子（电磁力）、胶子（强相互作用）、W/Z 玻色子（弱相互作用）
  - **希格斯玻色子**：质量的来源

## 医学成像

### 核磁共振 (MRI)
氢原子核自旋磁矩发生能级分裂 → 磁场 → 共振 → 驰豫（不同组织氢原子驰豫时间不同）→ 捕捉信号 → 构图

### FMRI（功能性磁共振成像）
检测血氧（能量消耗），判断大脑如何运行，脱氧血红蛋白具有顺磁性。

## 电子器件

### 电子管
热阴极发射自由电子，用于信号放大、开关。

### 晶体管
半导体材料载流子的运动，用于信号放大、开关。

### 半导体
- 纯净硅是本征半导体（通过热激发成对产生载流子）
- 硅和其他材料掺杂成 N 型或 P 型（可以控制载流子浓度）

## 视觉技术

### 3D 眼镜
偏振镜片或不同颜色的镜片产生两种图像，欺骗大脑重构 3D 图像。

### 全息技术
重建物体光场，记录振幅和相位。

## 识别技术

### RFID
射频识别技术。

## 显微镜技术

### 扫描隧道显微镜
极细的针尖，利用量子隧穿效应，检测电流变化重构原子级三维形貌图。

### 原子力显微镜
针尖原子与样品原子的相互作用力，微悬架产生微小偏转，激光捕捉偏转并进行放大。

## 纳米材料

| 材料 | 特点 |
|------|------|
| **碳纤维** | 微米级，强度高，导电性好，石墨微晶层叠，按束生产（几万根纤维） |

## 量子力学

### 量子计算
利用量子叠加和纠缠进行计算。

### 量子场论
粒子是场的激发，波是场的概率幅演化。

### 量子力学诠释
- **退相干**：量子系统与环境的相互作用导致量子态退化为经典态
- **真空灾难**：量子场论预言的真空能量与观测值之间存在巨大差异

### 统计力学
- **经典粒子**：可区分，交换后是一个新的物理态
- **玻色子**：不可区分，交换后波函数相同
- **费米子**：不可区分，交换后波函数相反

## 力学

### 牛顿力学
核心是力，一个二阶微分方程。

### 哈密顿力学
核心是能量，两个一阶微分方程。

## 相对论

### 狭义相对论
时间和空间是相对的，洛伦兹变换，相对性原理，光速不变原理。

### 相对论协变
物理定律在不同参考系变换下保持不变。

- **固有时**：观察者自身参考系中测量的时间
- **坐标时**：其他参考系中测量的时间

## 核物理

### 核裂变
中子撞击重原子使其裂变释放能量，产生新的中子链式反应，需要超过临界质量，新产生的快中子需要减速为慢中子。

### 核聚变
需要高温或强大的引力使原子核聚变，磁约束或惯性约束。

### 等离子体
高温或强磁场下原子中的电子挣脱束缚，与原子核分离，宏观上电中性，微观上是带电粒子。低温等离子体（电子很热，离子接近室温）。

## 光学

### 光的散射
- **瑞利散射**：微粒尺寸远小于光的波长，与波长四次方成反比
- **米氏散射**：微粒尺寸接近光的波长，均匀散射
- **拉曼散射**：光子与分子转动或振动能级交换能量
- **布里渊散射**：光子与声子交换能量

### 光的色散
介质对不同频率的光折射率不同。

### 激光
增益介质、泵浦源、谐振腔。

### 半波损失
反射光相比于入射光相位相差半个波长，菲涅尔公式可证明，光疏到光密。

| 概念 | 说明 |

| **相速度** | 单色波的速度 |
| **群速度** | 波包的速度 |

## 宇宙学

| 概念 | 说明 |
|------|------|
| **多普勒效应** | 相互靠近，频率升高。相对运动使空间中各处的频率不同，光会出现横向多普勒效应 |
| **宇宙学红移** | 空间膨胀使波长增大 |
| **宇宙微波背景辐射** | 黑体辐射光谱，宇宙的第一束光 |
| **黑体辐射** | 完全吸收光，辐射只与温度有关 |
| **三体问题** | 三个天体之间的引力相互作用问题 |

## 凝聚态物理

### 晶体结构
- **晶体**：粒子在空间中周期性排列，长程有序
- **非晶**：原子排列长程无序
- **准晶**：原子排列有序，有特殊的旋转对称

| 概念 | 说明 |
|------|------|
| **原胞** | 晶体中最小重复单元，只包含一个格点，由三个基矢围成的六面体 |
| **晶胞** | 主要体现出晶体的对称性 |
| **结构基元** | 对应一个格点 |
| **旋转对称性** | 由晶体点阵决定 |
| **傅里叶变换** | 物理上的位置和动量恰好是傅里叶变换的一对共轭变量 |

### 能带理论
- **声子**：晶格振动产生的格波的能量量子。能量量子可以抽象为粒子，方便使用处理粒子的各种方式解决问题
- **布里渊区**：倒格子中的 W-S 原胞
- **布洛赫定理**：晶体中电子波函数的形式，说明倒易空间具有周期性
- **晶格振动**：与晶格热容有关
- **电子热容**：和导电性有关
- **能带理论**：单电子能级是分立的，晶体中电子能级发生分裂，形成能带
- **价带**：最外层电子已经填充满的能带
- **导带**：电子未填充满的能带
- **费米面**：整个晶体中，波矢空间里电子占据态和未占据态的分界面
- **理论基础**：绝热近似、单电子近似、布洛赫定理；具体处理方式：近自由电子近似、紧束缚近似（如何解薛定谔方程）

## 其他概念

- **分子装配机（纳米工厂）**：操纵每一个原子来构建物质
- **离心机**：分离不同密度的物质
- **热量约束**：减少热量摄入延长寿命，降低新陈代谢，能量缺乏时自噬细胞清理机制
- **干细胞**：强大的分化能力，胚胎干细胞、成人干细胞（造血干细胞）
